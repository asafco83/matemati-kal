# מתמטי-קל

לומדה ללימוד ולתרגול עצמי של מתמטיקה, מכיתה א' ועד י"ב.

כל נושא בנוי משלושה חלקים:

- **לומדים**: הסבר קצר וברור, שרטוטים, שיטת עבודה לפי שלבים וטעויות נפוצות.
- **דוגמאות פתורות**: פתרון שנחשף צעד אחר צעד.
- **תרגול**: שאלות אקראיות בשלוש רמות קושי, עם רמז, בדיקה מיידית ודרך פתרון מלאה לכל שאלה. חמש תשובות נכונות מזכות בכוכב.

## מצב התוכן

14 נושאים מלאים, ועוד 38 נושאים מתוכננים שמופיעים בלומדה עם התווית "בקרוב".

| מסלול | נושאים מלאים |
|---|---|
| מספרים וחשבון | חיבור וחיסור, לוח הכפל, סדר פעולות חשבון |
| שברים, עשרוניים ואחוזים | חיבור וחיסור שברים, אחוזים |
| גאומטריה | היקף ושטח של מלבן, זוויות במשולש, משפט פיתגורס |
| אלגברה | משוואות ממעלה ראשונה, משוואות ריבועיות |
| פונקציות וגרפים | הפונקציה הקווית |
| טריגונומטריה | טריגונומטריה במשולש ישר זווית |
| חדו"א | נגזרת של פולינום |
| הסתברות וסטטיסטיקה | הסתברות |

## הרצה מקומית

```bash
npm install

npm test         # בדיקת כל מחוללי השאלות
npm run build    # בנייה לתיקיית dist
```

## התחברות וסנכרון (Firebase)

בלי הגדרות Firebase הלומדה עובדת במצב מקומי: פרופילים והתקדמות נשמרים בדפדפן.
כדי להפעיל התחברות עם Google וסנכרון בין מכשירים:

1. ב-Firebase Console, בפרויקט `matemati-kal`: להפעיל **Authentication** עם ספק Google, וליצור **Firestore Database**.
2. ב-Project settings, להוסיף Web app ולהעתיק את `apiKey`, `messagingSenderId` ו-`appId` אל `src/firebaseConfig.ts`.
3. לפרוס:

```bash
npm install -g firebase-tools
firebase login
npm run build
firebase deploy
```

הפקודה האחרונה מעלה את האתר ל-Firebase Hosting וגם את כללי האבטחה שב-`firestore.rules`
(כל משתמש קורא וכותב רק את המסמך של עצמו).

## הוספת נושא

כל נושא הוא אובייקט `Topic` (ראו `src/lib/types.ts`) באחד הקבצים שבתיקייה `src/content`:
שיעור, דוגמאות, ופונקציה `generate(level)` שמחזירה שאלה אקראית עם תשובה, רמז ופתרון.
אחרי שמוסיפים נושא מסירים אותו מרשימת `soonTopics` ומריצים `npm test`.
